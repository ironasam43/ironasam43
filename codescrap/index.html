CodeScrap — Support

A scrapbook for QR codes and barcodes. Free, offline, no account.

Privacy Policy

What CodeScrap Does

Scan a QR code or barcode with the camera, file it into a category, and bring it back on your iPhone screen whenever you need it — tickets, membership cards, Wi-Fi codes, product barcodes, links. You can also type a text string and generate a code without a camera.

Getting Started

  1. Launch the app. The top screen shows a Scan Code row and your category list (empty on first launch).
  2. Tap + to add a category, open it, then tap + to add a code.
  3. Tap the image area to scan a code with the camera, or type text into the Code field and tap Generate.
  4. Open a saved code to show it full-size. Swipe left or right to move between codes in the same category.
  5. Scan Code on the top screen opens Quick Code: scan a code and copy its text. Saving is optional.

Frequently Asked Questions

Where are my codes stored?

Entirely on your iPhone, inside the app's own storage area (Documents/Library.codescrap/). Nothing is uploaded anywhere. There is no account and no sign-in.

What happens when I get a new iPhone?

Because the data lives in the app's Documents folder, it is included in your standard iPhone backup (iCloud Backup or an encrypted computer backup). Restoring that backup onto a new iPhone restores your codes as well. CodeScrap itself does not sync between devices, so if you set up a new iPhone as new (without restoring a backup), the codes will not carry over.

Which codes are supported?

Scan: QR, Aztec, PDF417, Code 128, Code 39, ITF-14, EAN-13, EAN-8, UPC-A, UPC-E, Data Matrix, Code 93.

Generate from typed text: QR, Aztec, PDF417, Code 128, Code 39, ITF-14, EAN-13, EAN-8, UPC-A, UPC-E. (Data Matrix and Code 93 can be scanned but not generated. Code 128 accepts ASCII characters only. The 1D codes have fixed digit counts — for example EAN-13 needs 13 digits — and the Generate menu only lists the types that can actually encode the text you typed.)

A code will not scan. What can I do?

  • Allow camera access. If you declined it earlier, turn it on in Settings > CodeScrap > Camera.
  • Fill more of the frame with the code, and pinch to zoom in (up to 8×) for small codes.
  • Avoid glare and shadows; a printed code behind glossy film or a dimmed phone screen is often the cause.
  • If the code is damaged or very low contrast, type its text into the Code field instead and generate it.

Does the saved image look different from the original?

Yes, on purpose. For code types CodeScrap can generate, it redraws the code as a clean, high-contrast black-and-white image, so it scans reliably on another device. For Data Matrix and Code 93 it keeps the cropped camera image instead, since those types cannot be regenerated.

Can I reorganize my codes?

Yes. Categories and codes can be renamed, reordered and deleted, and a code can be moved to another category. Deleting a category deletes the codes inside it.

Does the app use the internet?

No. CodeScrap works fully offline. The only outbound action is the banner at the bottom of the screens, which opens the App Store page for DeeperAI (another app by the same developer) in the App Store app.

プライバシーポリシー

CodeScrap でできること

カメラで QR コードやバーコードを読み取り、カテゴリーに分けて保存し、必要なときに iPhone の画面へもう一度呼び出せます。チケット・会員証・Wi-Fi の QR・商品バーコード・リンクなどに。手元にコードがないときは、文字列を入力してその場で生成することもできます。

使い方

  1. アプリを起動します。最初の画面に「コードを読み取り」の行とカテゴリー一覧が表示されます（初回は空です）。
  2. ＋ でカテゴリーを追加し、開いて、さらに ＋ でコードを追加します。
  3. 画像の領域をタップしてカメラで読み取るか、「コード」欄に文字列を入力して「生成」をタップします。
  4. 保存したコードを開くと大きく表示されます。左右スワイプで同じカテゴリー内の他のコードへ移動できます。
  5. 最初の画面の「コードを読み取り」は一時コードです。読み取って文字列をコピーするだけで、保存は任意です。

よくある質問

保存したコードはどこに保存されますか？

すべて iPhone の中、アプリ専用の保存領域（Documents/Library.codescrap/）に保存されます。どこにもアップロードされません。アカウントもログインもありません。

機種変更したらデータはどうなりますか？

データはアプリの Documents フォルダにあるため、通常の iPhone のバックアップ（iCloud バックアップ、または暗号化したパソコンへのバックアップ）に含まれます。そのバックアップから新しい iPhone を復元すれば、コードもそのまま復元されます。CodeScrap 自体は端末間で同期しないため、バックアップから復元せずに「新しい iPhone として設定」した場合は引き継がれません。

対応しているコードの種類は？

読み取り：QR、Aztec、PDF417、Code 128、Code 39、ITF-14、EAN-13、EAN-8、UPC-A、UPC-E、Data Matrix、Code 93。

入力した文字列からの生成：QR、Aztec、PDF417、Code 128、Code 39、ITF-14、EAN-13、EAN-8、UPC-A、UPC-E。（Data Matrix と Code 93 は読み取りのみで生成はできません。Code 128 は ASCII 文字のみ対応です。1 次元コードは桁数が決まっており——たとえば EAN-13 は 13 桁——「生成」メニューには、入力した文字列を実際に符号化できる種別だけが並びます。）

コードが読み取れないときは？

  • カメラの使用を許可してください。以前に拒否した場合は「設定 > CodeScrap > カメラ」からオンにできます。
  • コードが画面いっぱいに写るように近づき、小さいコードはピンチで拡大（最大 8 倍）してください。
  • 反射や影を避けてください。光沢フィルム越しの印刷や、暗くなった他のスマホの画面が原因のことがよくあります。
  • コードが破損している・コントラストが極端に低い場合は、「コード」欄に文字列を直接入力して生成してください。

保存した画像が元のコードと少し違って見えます

意図的な仕様です。CodeScrap が生成できる種別については、他の端末で確実に読み取れるよう、白黒のくっきりした画像に描き直して保存します。生成できない Data Matrix と Code 93 については、カメラ画像からコード部分を切り出したものをそのまま保存します。

あとから整理し直せますか？

できます。カテゴリーもコードも、名前の変更・並べ替え・削除ができ、コードは別のカテゴリーへ移動できます。カテゴリーを削除すると、その中のコードも削除されます。

インターネットに接続しますか？

しません。CodeScrap は完全にオフラインで動作します。外部へ出る唯一の動作は、画面下部のバナーをタップしたときに、同じ開発者の別アプリ「DeeperAI」の App Store ページを App Store アプリで開くことだけです。
